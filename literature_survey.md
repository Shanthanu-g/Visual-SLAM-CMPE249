# Recent Literature and State-of-the-Art Survey

## Survey Scope

The survey covers work published from 2023 through 2025. ORB-SLAM3 is retained as the project baseline because it is mature, reproducible, and supports stereo and visual-inertial configurations, although its original publication predates this survey window. Recent research increasingly combines learned correspondence, global optimization, neural scene representations, Gaussian splatting, and tightly coupled multi-sensor fusion. Most of these methods offer capabilities beyond the semester implementation but help define meaningful comparisons and extensions.

## Selected Systems

| Work | Year | Main contribution | Relevance and limitation for this project |
|---|---:|---|---|
| [Deep Patch Visual Odometry (DPVO)](https://proceedings.neurips.cc/paper_files/paper/2023/file/7ac484b0f1a1719ad5be9aa8c8455fbb-Paper-Conference.pdf) | 2023 | Uses learned sparse patch correspondence and differentiable bundle adjustment for accurate, efficient monocular visual odometry. | Demonstrates that learned matching can improve robustness without dense optical-flow cost. It is a useful future comparison, but it is monocular VO rather than a complete stereo SLAM system with loop closure. |
| [GO-SLAM: Global Optimization for Consistent 3D Instant Reconstruction](https://openaccess.thecvf.com/content/ICCV2023/html/Zhang_GO-SLAM_Global_Optimization_for_Consistent_3D_Instant_Reconstruction_ICCV_2023_paper.html) | 2023 | Combines tracking, global pose/depth optimization, loop closure, and online neural reconstruction for globally consistent dense mapping. | Shows the direction from sparse localization toward dense, globally optimized reconstruction. Its neural reconstruction pipeline adds more integration and GPU cost than the semester project needs. |
| [NeRF-LOAM: Neural Implicit Representation for Large-Scale Incremental LiDAR Odometry and Mapping](https://openaccess.thecvf.com/content/ICCV2023/html/Deng_NeRF-LOAM_Neural_Implicit_Representation_for_Large-Scale_Incremental_LiDAR_Odometry_and_ICCV_2023_paper.html) | 2023 | Uses a neural signed-distance representation for incremental LiDAR odometry, mapping, and mesh reconstruction in large environments. | Relevant to road-scale LiDAR mapping and to the original dense-map idea. It confirms that high-quality LiDAR mapping is a distinct subsystem, not a native output of ORB-SLAM3. |
| [SplaTAM: Splat, Track & Map 3D Gaussians for Dense RGB-D SLAM](https://openaccess.thecvf.com/content/CVPR2024/html/Keetha_SplaTAM_Splat_Track__Map_3D_Gaussians_for_Dense_RGB-D_CVPR_2024_paper.html) | 2024 | Represents the scene with 3D Gaussians and jointly supports camera tracking, dense mapping, and novel-view rendering from RGB-D input. | Provides a modern dense-mapping reference. Its RGB-D indoor assumptions and emphasis on photorealistic reconstruction do not directly match outdoor stereo driving. |
| [Gaussian Splatting SLAM](https://openaccess.thecvf.com/content/CVPR2024/html/Matsuki_Gaussian_Splatting_SLAM_CVPR_2024_paper.html) | 2024 | Uses 3D Gaussian scene representation with camera tracking and map optimization for photorealistic dense SLAM. | Illustrates the rapid shift toward dense Gaussian maps. It is valuable future work, but it would distract from evaluating localization reliability and control within one semester. |
| [Loopy-SLAM: Dense Neural SLAM with Loop Closures](https://openaccess.thecvf.com/content/CVPR2024/papers/Liso_Loopy-SLAM_Dense_Neural_SLAM_with_Loop_Closures_CVPR_2024_paper.pdf) | 2024 | Adds loop-closure constraints and pose-graph correction to dense neural implicit SLAM. | Reinforces that loop closure is essential for controlling long-term drift. ORB-SLAM3 already provides a mature loop-closing baseline, making it lower risk for this project. |
| [SNI-SLAM: Semantic Neural Implicit SLAM](https://openaccess.thecvf.com/content/CVPR2024/papers/Zhu_SNI-SLAM_Semantic_Neural_Implicit_SLAM_CVPR_2024_paper.pdf) | 2024 | Jointly estimates camera motion while constructing geometric, appearance, and semantic scene representations. | Supports the longer-term idea of object-aware maps. Semantic mapping is excluded from the core scope because it requires additional models, labels, metrics, and compute. |
| [AirSLAM: An Efficient and Illumination-Robust Point-Line Visual SLAM System](https://arxiv.org/abs/2408.03520) | 2024 | Combines learned point and line features with classical optimization and relocalization to improve robustness under short- and long-term illumination changes. | Directly motivates the project's day/night and low-light tests. AirSLAM is a strong candidate for later comparison if ORB-SLAM3 exhibits lighting-related failures. |
| [FAST-LIVO2: Fast, Direct LiDAR-Inertial-Visual Odometry](https://arxiv.org/abs/2408.14035) | 2024 | Tightly fuses raw LiDAR, IMU, and image measurements in a unified voxel map using sequential Kalman-filter updates. | Represents the correct technical direction for true LiDAR-visual-inertial fusion. Implementing it alongside ORB-SLAM3 would exceed the semester scope, so LiDAR fusion is retained as future work. |
| [MASt3R-SLAM: Real-Time Dense SLAM with 3D Reconstruction Priors](https://openaccess.thecvf.com/content/CVPR2025/html/Murai_MASt3R-SLAM_Real-Time_Dense_SLAM_with_3D_Reconstruction_Priors_CVPR_2025_paper.html) | 2025 | Uses learned 3D reconstruction priors to perform dense tracking and mapping without relying on a conventional fixed camera model in the same way as classical pipelines. | Shows how foundation-style 3D priors may reduce calibration and correspondence limitations. Its novelty and complexity make it a research comparison rather than the implementation baseline. |

## Synthesis of the Literature

Three trends are clear. First, learned correspondence systems such as DPVO and AirSLAM target failure modes of hand-engineered visual features. Second, dense neural or Gaussian representations such as GO-SLAM, SplaTAM, Gaussian Splatting SLAM, Loopy-SLAM, and SNI-SLAM combine localization with higher-quality reconstruction. Third, FAST-LIVO2 and NeRF-LOAM demonstrate that robust LiDAR integration requires a purpose-built estimation or mapping architecture rather than simply attaching LiDAR data to a visual SLAM system.

For this project, ORB-SLAM3 remains the appropriate baseline because the main research question concerns reproducible behavior across real-road recordings and controlled CARLA conditions, not creation of a new map representation. The most useful contribution is a controlled evaluation harness with transparent ground-truth isolation, consistent metrics, failure reporting, and a closed-loop demonstration. AirSLAM or DPVO can be added as one comparison only if the core pipeline is stable by the end of Week 10.

## Identified Gap

The individual ingredients are established, and many papers report benchmark accuracy. A manageable project gap remains in demonstrating, on consumer hardware, how a mature feature-based stereo SLAM system behaves when the same evaluation design spans recorded road data, controlled simulator stressors, runtime measurement, and pose-based feedback control. This is primarily a systems-evaluation contribution rather than a new SLAM algorithm.
